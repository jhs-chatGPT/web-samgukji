웹삼국지 v69-9 상점 실기능 확장

이번 버전
1. 소모품 실제 사용
- 약초: 행동력 +3
- 금창약: 행동력 +5
- 해독산: 행동력 +4
- 명주: 행동력 +2 / 명성 +2
- 회복 소모품은 하루 1회 사용
- 사용 시 실제 보유 수량 1개 감소

2. 책 연구
- 손자병법: 군략 EXP +35
- 육도: 통솔 EXP +35
- 삼략: 군략 EXP +20 / 정치 EXP +20
- 오자병법: 통솔 EXP +20 / 군략 EXP +20
- 맹덕신서: 지략 EXP +40 / 군략 EXP +30
- 연구 AP 5 / 2일
- EXP 100마다 해당 능력 +1, 최대 100
- 책은 연구해도 소모되지 않음

3. 장신구/장식품 실제 효과
- 장식품을 실제 장착 슬롯으로 변경
- 비단 장식: 매력 +1
- 향낭: 외교 +1 / 매력 +1
- 금제 관식: 정치 +2 / 매력 +2
- 장신구/장식품은 상점의 장신구 탭에서 함께 표시

4. 도시별 상점 가격/재고
- 현재 장수가 머무는 도시 기준으로 가격과 재고 산정
- 도시 상업/규모/월별 시세에 따라 가격 변동
- 아이템별 재고 차이
- 구매하면 해당 달/도시의 재고 감소
- 월이 바뀌면 자동으로 신규 재고 생성
- 품절 표시 및 구매 차단

5. 세이브 호환
- 기존 v69-8 세이브는 신규 필드가 없어도 자동 기본값 적용
